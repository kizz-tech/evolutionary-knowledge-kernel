# The ordinary path, measured correctly

Runtime increment: **0.11.0**, planned, after [0.10.1](../0.10.1/README.md). It
serves the accepted [1.0 target](../1.0/spec.md): past work measurably improves
the next work, in every host, proven in real use. 0.10.0 delivered the
mechanisms; the first week of real use showed that their measurements cannot be
trusted yet and that unjudged held results would be deleted from 2026-11-01.
0.10.1 stops the loss and the misattribution; 0.11 makes capture, the owner's
review, entry, publication and host connections correct and fast enough for the
field-use comparison that the selected course starts with.
