# EKK 0.4.0 — first public release candidate

First research prerelease · Apache-2.0 · Kizz.

This candidate introduces a working local runtime for the supplied Architecture
0.1 and record format 0.1. It is offered as a research prototype: a way to inspect
sources, decision grounds, expectations, and revisions across agent tasks.
The model-effectiveness study remains `designed_not_run`.

Included: Python runtime and CLI; model/application/adapter boundaries; source
capture; scoped context; proposals and a Git writer; acceptance verification;
review and export operations; local profiles and portable workspace bindings;
method packs; synthetic starter examples; tests; runnable setup instructions;
and the research protocol.

The release source export excludes active knowledge stores, personal or company
sources, local profiles, runtime state, and development Git history. The exact
historical starter remains labeled as such. Older compatibility modules support
fixtures and historical replay; new integrations use the current agent entry.

See [validation](release-validation.md) for implementation checks. Trusted local
operation is not a multiuser security boundary. Agent integration is not an
always-on capture service. No measured productivity or model-improvement claim
is made. This release does not include a hosted service or a completed study.
