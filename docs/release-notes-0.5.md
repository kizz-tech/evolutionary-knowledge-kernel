# Runtime 0.5 — personal entry and transferable methods

This checkout replaces the active legacy routing with one current runtime and
moves the product center to personal entry, shared continuity and revisable
methods. Record format 0.1 and existing owner boundaries remain unchanged.

- Explicit personal home and opt-in personal projection; exact-reference resume.
- Current commitments, visible results/questions and method offers at entry.
- Inert method artifact, local evaluation, acceptance, fresh-process admission,
  exact owner-authorized transfer and independent receiving adoption.
- Adverse outcome, review, durable quarantine, accepted retirement and next revision.
- Complete deterministic two-participant example and separate four-arm protocol.
- Historical runtimes and legacy-only tests removed from the installed package.

Breaking change: legacy CLI commands and imports are no longer active APIs.
An English historical edition remains under `archive/runtime-0.4` for explicit
replay; exact untranslated sources remain in the v0.4.0 tag. This is a deliberate prerelease migration, not an automatic data migration.

The public documentation, historical designs, fixtures and validator messages
are now in English. The [translation provenance](runtime-starter-provenance.md)
distinguishes translated bytes from preserved originals. English method packs
use `0.1.0-design.en`; an existing store's exact old pack pins require its matching
provider or a separately reviewed owner-authorized pack-lock update. No existing
store is automatically migrated by installation.

This is a research preview. It does not establish model productivity, human
learning, hostile multiuser isolation or live company integration. See
[validation](release-validation.md).
