# Граница безопасности

Этот комплект не содержит промышленного контроллера доступа. Валидатор не проверяет личность,
полномочия автора или конфиденциальность текста. Не выдавайте сотрудникам полный Git-клон,
если им запрещена часть его файлов или истории.

Источники недоверенны. Packs не запускают код при загрузке. Для будущего runtime нужны
проверки path traversal, symlink escape, разрешённых источников, CAS, изоляции кеша и отзыва доступа.
Серверный principal устанавливается транспортом и авторизацией, а не входным YAML.

Не используйте публичные issues для реальных секретов и клиентских данных.
Контакт для приватного сообщения об уязвимости задаётся сопровождающими до публичного релиза.
