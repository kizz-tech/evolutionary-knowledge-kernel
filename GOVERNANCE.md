# Project governance

EKK is maintained in the [Kizz organization](https://github.com/kizz-tech/evolutionary-knowledge-kernel).
The maintainer reviews changes and tags releases. Experimental results remain
separate from release approval; no result is implied by publishing the code.

Proposals should state the problem, evidence, costs, and intended change.
Maintainers review code and release decisions separately from empirical claims.
Each knowledge owner chooses its own applicable methods and accepted decisions;
an upstream change cannot silently change a company's policy.

A demonstration receipt is not evidence of real authority. An editable file
claiming authority does not confer it. Negative results and simpler alternatives
are valid outcomes of the research.
